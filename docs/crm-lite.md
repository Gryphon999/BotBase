# CRM-лайт (октябрь 2026)

Дополнение к боту, превращающее кабинет в простую CRM для салона. Всё построено вокруг бота: он записывает,
напоминает и возвращает клиентов, а кабинет показывает результат.

| # | Функция | Где | Как устроено |
|---|---------|-----|--------------|
| 1 | Ручная запись | «Записи» → «Новая запись» | `POST /api/appointments/manual` → `BookingService` (та же проверка, что у бота: часы работы, занятость, мастера) |
| 2 | Напоминание за сутки | «Автосообщения» | `AutomationWorker`: за ≤24 ч до визита, не раньше 12 ч после записи, кнопки «Приду / Отменить» (`callback_query` в `WebhookController`) |
| 3 | База клиентов | «Клиенты» | `Client` — одна карточка на номер (`PhoneKey` = цифры номера); заметки, история, сумма визитов |
| 4 | Перенос / отмена | меню записи | `PUT /{id}/reschedule`, `PATCH /{id}/status` с `notifyClient: true` — клиент получает сообщение в Telegram |
| 5 | Мастера | «Мастера» | `Master` + процедуры + личное расписание (`WorkSchedule.MasterId`). Без мастеров — всё как раньше |
| 6 | Отзыв и «давно не были» | «Автосообщения» | оценка 1–5 через 2 ч после визита (низкая → уведомление владельцу), «давно не были» один раз за перерыв |
| 7 | Статистика | «Статистика» | `GET /api/stats?month=` — записи бота/ручные, выручка, неявки, новые клиенты, услуги, мастера |

## Важные правила

- **Время.** Записи хранятся «по часам бизнеса» (Kind=Utc), «сейчас» считается в часовом поясе бизнеса
  (`BusinessClock`, по умолчанию `Asia/Yerevan`). Ночью (21:00–9:00) автосообщения не отправляются.
- **CRM-интеграция не меняется.** Статусы записи (`Pending/Confirmed/Cancelled`), поля вебхука и старые адреса API
  прежние; новые данные — отдельными полями. «Не пришёл» хранится флагом `NoShow`, а не новым статусом.
- **Автосообщения сохраняются в разговор**, чтобы ИИ понимал, на что отвечает клиент.
- **Только тот, кому пришла кнопка, может её нажать** (проверка чата клиента).
- Миграция `AddCrmLite` создаёт карточки клиентов из старых записей и помечает прошедшие визиты обработанными,
  чтобы автосообщения не писали о старых визитах.

# Админка и техподдержка BotBase

## Вход администратора
Админ-аккаунт создаётся автоматически при старте приложения из переменных Railway:

| Переменная | Значение |
|---|---|
| `Admin__Email` | email для входа в админку |
| `Admin__Password` | надёжный пароль (12+ символов) |
| `Admin__ResetPassword` | `true` — только если нужно сменить пароль: задать новый `Admin__Password`, задеплоить, затем удалить эту переменную |

Админка: `https://<домен>/admin/login`. Пароль хранится в БД в виде хеша; при обычных деплоях не меняется.

Возможности: список клиентов и статистика, проверка и перезапуск бота (повторная регистрация webhook),
вход в кабинет клиента (токен на 1 час), отключение/включение (бот молчит, вход в кабинет закрыт, данные сохраняются),
удаление навсегда (с подтверждением названием бизнеса).

## Уведомления техподдержки
**Почта (Gmail SMTP)**
1. Google-аккаунт → Безопасность → включить двухэтапную аутентификацию.
2. https://myaccount.google.com/apppasswords → создать пароль приложения «BotBase».
3. В Railway добавить: `Smtp__User` = gmail-адрес, `Smtp__Password` = пароль приложения (16 букв), при желании `Smtp__From`.

**Telegram**
1. В @BotFather создать бота для уведомлений (отдельного, не клиентского).
2. В Railway: `Support__TelegramBotToken` = токен этого бота.
3. Написать этому боту /start, узнать свой Chat ID у @userinfobot.

**В админке → Настройки** указать email техподдержки и Chat ID. Каналы, которые не настроены, просто пропускаются.

Кто что получает:
- новое обращение или ответ клиента → письмо на email техподдержки + сообщение в Telegram;
- ответ администратора → письмо клиенту на email его аккаунта.
